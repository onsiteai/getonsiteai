# getonsiteai

Landing page for [getonsiteai.com](https://getonsiteai.com) — The AI App for Contractors.

Built with React, TypeScript, Tailwind CSS v4, deployed via Cloudflare Pages.

## Development

```bash
bun install
bun dev
```

## Build

```bash
bun run build
```

## Deploy

Connected to Cloudflare Pages. Pushes to `main` trigger automatic deployments.

- Build command: `bun run build`
- Output directory: `dist`
